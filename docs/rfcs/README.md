# Design RFCs

Store cross-cutting design notes here — proposals about how Egregore relates to
other systems, or larger design directions that do not fit a single ADR.

An ADR (`docs/adr/`) records a decision that changes Egregore's own shape. An
RFC records a proposal or positioning note, often spanning more than one
decision, and may be a discussion draft rather than an accepted decision.

Use filenames like `0001-vertere-integration.md`.

- [0001: Egregore as Vertere's Code-Intelligence and Provenance Engine](0001-vertere-integration.md)
